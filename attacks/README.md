# Corpus de ataques

Las semillas y mutadores viven en `src/tfm_lab/attacks/`. Este directorio versiona el **corpus expandido**
que genera la campaña (una carga por variante) como evidencia. Se regenera con `make campaign` y queda en
`results/`; aquí se guarda una copia estable de las semillas revisadas manualmente para el anexo de la memoria.
